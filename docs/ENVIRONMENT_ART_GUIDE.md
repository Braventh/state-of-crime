# Environment art guide

Low-resolution procedural canvas with crisp scaling, ochre pavement edges and a violet shadow key. Use large silhouette changes first: vertical towers, low rooflines with open water, then boxy cargo yards with gantries. Give every facade a silhouette, inset opening, alternating trim and lit accents. Use cool depth layers and warmer road detail so actors and interactable markers read at speed.

Characters use layered pixel silhouettes with separate heads, outerwear, limbs, gait and a clear direction of travel. Vehicle profiles include cab, windows, bumpers, lamps, rims and body highlights. UI uses a restrained deep-plum/pale-cream palette with coral denoting action and mint denoting safe travel. No imported media or proprietary reference imagery.
